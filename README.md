# EchoGuard AI

## About the Project

EchoGuard AI is a student-focused request management prototype designed to help track student requests, monitor due dates, organize supporting evidence, and assist faculty in reviewing pending requests.

## Features

* Track student requests and their statuses.
* Monitor expected due dates and delayed requests.
* Organize supporting evidence and verification status.
* Provide faculty monitoring and request review features.
* Display rule-based warnings and suggested follow-up actions.

## Technologies Used

* Python
* Streamlit
* Pandas
* SQLite
* CSV

## How to Run Locally

1. Install Python.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run the application using `python -m streamlit run echoguard_app_role_based.py`.

## Project Status

This is a student prototype. Features and workflows should be tested before real-world use.
